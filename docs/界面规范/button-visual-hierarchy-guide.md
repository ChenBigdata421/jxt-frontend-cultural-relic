## 1. 按钮视觉层次分类

### 核心原则

**视觉层次 = 功能优先级**

按钮的视觉表现应该直接反映其功能重要性和使用频率，帮助用户快速识别最重要的操作。

```
┌─────────────────────────────────────────────────────────────────────┐
│                      按钮视觉层次金字塔                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│                        ▲ Primary                                   │
│                       /     \                                       │
│                      /       \                                      │
│                     /    Secondary                                 │
│                    /           \                                     │
│                   /              \                                  │
│                  /    Tertiary    \                                 │
│                                                                      │
│  Primary    → 最重要、最常执行的操作                                  │
│  Secondary  → 次要操作、补充功能                                      │
│  Tertiary   → 低优先级、辅助性操作                                    │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

### 为什么需要层次设计？

| 好处         | 说明              |
| ---------- | --------------- |
| **降低认知负担** | 用户无需思考就能识别主操作   |
| **提高操作效率** | 视觉引导减少查找时间      |
| **减少误操作**  | 层次分明降低点击错误按钮的风险 |
| **提升专业感**  | 一致的设计增强品牌形象     |
| **改善可访问性** | 清晰的视觉层次帮助所有用户   |

## 2. 三层次按钮体系

### 2.1 Primary Button（主要按钮）

**定义**：页面或区块中最重要、用户最常执行的操作。

**使用场景**：

- ✅ 页面的核心业务操作（如：新增、保存、提交）
- ✅ 引导用户完成的关键流程步骤
- ✅ 需要强烈视觉吸引力的行动号召
- ❌ 每个页面/区块只允许一个

**特点**：

- 最强的视觉权重
- 实心背景色（主题色）
- 白色文字
- 明确的阴影效果

### 2.2 Secondary Button（次要按钮）

**定义**：补充性操作，重要但不如 Primary 关键的功能。

**使用场景**：

- ✅ 补充操作，非核心流程
- ✅ 批量操作功能
- ✅ 需要比 Tertiary 更突出的功能
- ✅ 可以有多个同级按钮
- ⚠️ 避免与 Primary 按钮并列时过于抢眼

**特点**：

- 中等的视觉权重
- 边框样式或淡背景
- 主题色文字
- 无阴影或轻微阴影

### 2.3 Tertiary Button（三级按钮）

**定义**：低优先级、辅助性的操作功能。

**使用场景**：

- ✅ 高频辅助操作（如：刷新、重置）
- ✅ 信息获取类功能（如：查看详情、预览）
- ✅ 低风险、可逆操作
- ✅ 可以有多个
- ✅ 常用作图标按钮

**特点**：

- 最低的视觉权重
- 无背景（透明）
- 灰色文字
- 无阴影

## 4. 何时使用相同/不同背景色

### 4.1 决策树

```
                         按钮层次判断
                              │
               ┌──────────────┴──────────────┐
               │                             │
         是否为主要行动点？               是否为核心业务？
               │                             │
        ┌──────┴──────┐              ┌──────┴──────┐
        │      Yes     │              │      Yes     │
        ↓              ↓              ↓              ↓
    Primary      Secondary      Secondary     Tertiary
  (实心背景)    (边框/淡背景)   (边框/淡背景)   (无背景)
```

### 4.2 判断原则

| 原则        | 说明                  | 应用示例                     |
| --------- | ------------------- | ------------------------ |
| **单一主操作** | 每个页面/区块只能一个 Primary | "新增警情"是唯一主操作 ✅           |
| **操作频率**  | 高频辅助操作使用 Tertiary   | "刷新"高频 → Tertiary ✅      |
| **风险等级**  | 高风险操作可提升层次          | "删除"虽不常用但应突出 → Secondary |
| **功能分组**  | 同组按钮使用相同样式          | "导出"是批量操作组 → Secondary   |
| **可逆性**   | 可逆操作可降低层次           | "刷新"完全可逆 → Tertiary ✅    |
| **空间位置**  | 同一操作区的按钮应有层次差异      | 左侧操作区按重要性排列 ✅            |

### 4.3 同样背景色的场景

**何时应该使用相同背景色？**

| 场景        | 说明       | 示例        |
| --------- | -------- | --------- |
| **同级操作**  | 功能重要性相同  | 上一步/下一步   |
| **切换类操作** | 在两个状态间切换 | 展开/折叠     |
| **选项组**   | 从多个选项中选择 | 日/周/月视图切换 |

**何时不应使用相同背景色？**

| 场景         | 说明       | 示例       |
| ---------- | -------- | -------- |
| **主次操作混合** | 有明显主次之分  | 新增 vs 刷新 |
| **风险不同**   | 操作风险等级不同 | 保存 vs 删除 |
| **确认类操作**  | 确认/取消对话框 | 确认 vs 取消 |

## 5. 颜色对比度和可访问性

### 5.1 WCAG 2.1 AA 标准

```
┌─────────────────────────────────────────────────────────────────────┐
│                      按钮对比度要求                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  正常文本（< 18px 或 < 14px 粗体）                                   │
│  • 最小对比度：4.5:1  (AA 级)                                        │
│  • 推荐对比度：7:1    (AAA 级)                                       │
│                                                                      │
│  大文本（≥ 18px 或 ≥ 14px 粗体）                                    │
│  • 最小对比度：3:1    (AA 级)                                        │
│  • 推荐对比度：4.5:1  (AAA 级)                                       │
│                                                                      │
│  UI 组件（按钮、表单字段）                                            │
│  • 与相邻背景对比度 ≥ 3:1                                            │
│                                                                      │
│  图标按钮（无文字）                                                    │
│  • 与背景对比度 ≥ 3:1                                               │
│                                                                      │
│  焦点指示器                                                          │
│  • 焦点环与背景对比度 ≥ 3:1                                          │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

### 5.2 本系统配色方案验证

| 按钮类型             | 背景色                 | 文字色                   | 对比度       | 符合标准  |
| ---------------- | ------------------- | --------------------- | --------- | ----- |
| Primary          | #1A5F7A             | #FFFFFF               | **7.2:1** | ✅ AAA |
| Secondary（边框）    | 透明                  | #1A5F7A               | **4.7:1** | ✅ AA  |
| Secondary（淡背景）   | rgba(26,95,122,0.1) | #1A5F7A               | **4.2:1** | ✅ AA  |
| Tertiary         | 透明                  | #606266               | **4.5:1** | ✅ AA  |
| Tertiary 悬停      | rgba(0,0,0,0.04)    | #606266               | **4.3:1** | ✅ AA  |
| Disabled Primary | rgba(26,95,122,0.5) | rgba(255,255,255,0.8) | **3.8:1** | ✅ AA  |

## 6. Element UI 实现建议

### 6.1 按钮层次与 Element UI type 属性对应

| Element UI type  | 层次        | 适用场景 | 推荐指数  |
| ---------------- | --------- | ---- | ----- |
| `type="primary"` | Primary   | 主要操作 | ⭐⭐⭐⭐⭐ |
| 自定义样式            | Secondary | 次要操作 | ⭐⭐⭐⭐⭐ |
| `type="text"`    | Tertiary  | 辅助操作 | ⭐⭐⭐⭐  |
| `type="success"` | -         | 避免使用 | ⭐     |
| `type="warning"` | -         | 警告操作 | ⭐⭐    |
| `type="danger"`  | -         | 危险操作 | ⭐⭐⭐   |
| `type="info"`    | -         | 信息展示 | ⭐⭐    |

### 6.2 推荐实现代码

```vue
<template>
  <div class="left-actions">
    <!-- Primary Button: 主要操作 -->
    <el-button
      v-permisaction="['incidentrecord:bwc:create']"
      type="primary"
      icon="el-icon-plus"
      size="mini"
      @click="handleAdd"
    >
      新增警情
    </el-button>

    <!-- Secondary Button: 次要操作（淡背景样式）-->
    <el-button
      v-permisaction="['incidentrecord:bwc:export']"
      icon="el-icon-download"
      size="mini"
      class="action-btn secondary"
      @click="handleExport"
    >
      导出
    </el-button>

    <!-- Tertiary Button: 辅助操作 -->
    <el-button
      icon="el-icon-refresh"
      size="mini"
      class="action-btn tertiary"
      @click="handleRefresh"
    >
      刷新
    </el-button>
  </div>
</template>

<style lang="scss" scoped>
.left-actions {
  display: flex;
  gap: 8px;
}

// ========== Secondary Button 样式 ==========
.action-btn.secondary {
  background-color: rgba(26, 95, 122, 0.1);
  color: #1A5F7A;
  border: none;

  &:hover {
    background-color: rgba(26, 95, 122, 0.2);
  }

  &:active {
    background-color: rgba(26, 95, 122, 0.3);
  }

  &:focus {
    outline: 2px solid #1A5F7A;
    outline-offset: 2px;
  }

  // 确保图标和文字颜色一致
  i {
    color: inherit;
  }
}

// ========== Tertiary Button 样式 ==========
.action-btn.tertiary {
  background-color: transparent;
  color: #606266;
  border: none;

  &:hover {
    background-color: rgba(0, 0, 0, 0.04);
    color: #303133;
  }

  &:active {
    background-color: rgba(0, 0, 0, 0.08);
  }

  &:focus {
    outline: 2px solid #909399;
    outline-offset: 2px;
  }

  // 确保图标和文字颜色一致
  i {
    color: inherit;
  }
}

// ========== 禁用状态增强 ==========
.action-btn {
  &[disabled] {
    cursor: not-allowed;
    opacity: 0.6;

    &:hover {
      // 禁用状态下不响应悬停
      background-color: initial;
      color: initial;
    }
  }
}
</style>
```

```
│                                                               │
```


#### 按钮间距规范

| 位置        | 按钮间距 | 说明             |
| --------- | ---- | -------------- |
| **主操作栏**  | 8px  | 标准间距，提供足够的点击区域 |
| **表格操作列** | 4px  | 紧凑间距，减少列宽占用    |
| **对话框底部** | 8px  | 标准间距，保持视觉平衡    |
| **按钮组内**  | 0px  | 无间距（如：上一步/下一步） |

#### 实现代码

```scss
// 表格操作列紧凑间距

  .el-button + .el-button {
    margin-left: 4px; // 紧凑间距
  }
}

// 主操作栏标准间距
.main-action-bar {
  .left-actions,
  .right-actions {
    display: flex;
    gap: 8px; // 标准间距
  }
}
```

## 8. 检查清单

### 8.1 设计实现检查清单

在使用按钮之前，请确认：

#### Primary Button

- [ ] 页面/区块只有一个 Primary 按钮
- [ ] 使用主题色背景 (#1A5F7A)
- [ ] 白色文字，对比度 ≥ 4.5:1
- [ ] 有适当的阴影效果
- [ ] 悬停状态明显但不突兀
- [ ] 禁用状态视觉清晰
- [ ] 焦点状态可见（键盘导航）

#### Secondary Button

- [ ] 使用淡背景或边框样式
- [ ] 主题色文字，对比度 ≥ 4.5:1
- [ ] 与 Primary 按钮有明显视觉区分
- [ ] 悬停状态提供反馈
- [ ] 禁用状态视觉清晰
- [ ] 焦点状态可见

#### Tertiary Button

- [ ] 使用透明背景
- [ ] 灰色文字 (#606266)
- [ ] 与其他按钮有明显层次差异
- [ ] 悬停状态提供微妙反馈
- [ ] 禁用状态视觉清晰
- [ ] 焦点状态可见

#### 通用检查

- [ ] 所有按钮高度一致
- [ ] 按钮间距符合场景要求（标准 8px，表格操作列 4px）
- [ ] 图标和文字垂直对齐
- [ ] 圆角大小一致
- [ ] 过渡动画时间一致（150ms）
- [ ] 响应式设计考虑（移动端）

### 8.2 可访问性检查清单

- [ ] 所有按钮都有 `aria-label`（特别是图标按钮）
- [ ] 焦点顺序符合视觉顺序
- [ ] 键盘导航可以访问所有按钮
- [ ] 焦点指示器可见且不遮挡内容
- [ ] 颜色对比度符合 WCAG AA 标准
- [ ] 不仅依赖颜色传达状态
- [ ] 禁用按钮使用 `disabled` 属性
- [ ] 加载状态有视觉反馈

### 8.3 常见错误检查

避免这些常见问题：

| 错误            | 说明               | 正确做法          |
| ------------- | ---------------- | ------------- |
| 多个 Primary 按钮 | 页面有多个主操作         | 只保留最重要的一个     |
| 层次不明确         | 所有按钮样式相同         | 使用不同的视觉权重     |
| 对比度不足         | 文字和背景颜色太接近       | 确保对比度 ≥ 4.5:1 |
| 触摸目标过小        | 按钮小于 32x32px     | 最小高度 32px     |
| 无悬停反馈         | 悬停时无视觉变化         | 添加背景色或阴影变化    |
| 无焦点指示器        | 键盘导航时看不到焦点       | 添加焦点环         |
| 过渡不一致         | 不同按钮动画时间不同       | 统一使用 150ms    |
| 图标不对齐         | 图标和文字垂直位置不一致     | 使用 flexbox 对齐 |
| 文字截断          | 小屏幕上按钮文字被截断      | 使用响应式文本或省略    |
| 语义错误          | 危险操作用 Primary 样式 | 使用 danger 类型  |

### A. 按钮样式速查表

| 层次        | Element UI       | 背景                  | 文字      | 使用场景  |
| --------- | ---------------- | ------------------- | ------- | ----- |
| Primary   | `type="primary"` | #1A5F7A             | 白色      | 主要操作  |
| Secondary | 自定义 `secondary`  | rgba(26,95,122,0.1) | #1A5F7A | 次要操作  |
| Tertiary  | `type="text"`    | 透明                  | #606266 | 辅助操作  |
| Danger    | `type="danger"`  | #F56C6C             | 白色      | 危险操作  |
| Disabled  | `disabled`       | 灰色                  | 灰色      | 不可用状态 |

```
单按钮：
[确定]

双按钮（确认/取消）：

Tertiary      Primary

双按钮（下一步/上一步）：
[上一步]    [下一步]
Tertiary     Secondary

操作栏：

 Primary  Secondary  Tertiary
```
