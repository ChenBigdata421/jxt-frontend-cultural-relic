# JXT 数字证据管理平台 - 界面设计规范

本项目是一个数字管理平台，面向公检法执法人员，执法人员在执法过程中，可通过音视频录制、图片拍摄、文字记录等多种方式，实时采集现场各类信息（统称为“媒体资料”），并将其统一汇聚至数字管理平台。平台根据业务需求，对媒体资料进行管理，包括信息关联、归档存储、内容标注、数据分析、监控告警等。通过对作业过程多方位地数字化系统化管理，不仅提升了执法工作的规范性和透明度，进而确保各项工作过程可审查、可追溯、可控制。请结合本项目的特点，使用UI UX Pro Max技能优化一下主框架页面。

## 一、设计原则

基于项目面向**公检法执法人员**的特性，界面设计应遵循以下核心原则：

### 1.1 核心价值导向

- **权威性**：体现司法系统的严肃性和权威感
- **专业性**：展示执法工作的规范性和专业性
- **安全性**：传递数据安全和可信赖的感觉
- **高效性**：支持执法人员快速完成操作，减少认知负担
- **可追溯性**：清晰的信息层级和操作记录展示

### 1.2 设计关键词

**专业、严谨、清晰、可信、高效**

## 总结

这份设计规范针对**JXT数字证据管理平台**的特殊性质（公检法执法场景），制定了：

1. **权威专业的色彩系统**：以司法蓝为主色调，体现执法系统的严肃性和权威性
2. **清晰易读的字体系统**：优先使用中文字体，确保专业感和可读性
3. **严格的间距系统**：基于8dp的规范间距，确保整体协调一致
4. **规范的组件样式**：详细定义了登录页、导航栏、菜单、按钮等核心组件的样式
5. **明确的状态指示**：针对证据管理的各种状态定义了颜色规范
6. **完善的动画规范**：定义了过渡时间和动画效果，提升交互体验
7. **响应式和无障碍支持**：确保系统在不同设备和场景下都能良好使用

这套规范可以帮助开发团队保持界面的一致性和专业性，同时满足执法人员对系统权威性、可靠性和高效性的要求。
